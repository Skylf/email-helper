# Bug: 高级模式「存草稿」点击后程序闪退 0xC0000409

**日期**: 2026-08-24
**版本**: v0.2B(开发中)
**优先级**: 高

## 现象
高级模式配置页点击「存草稿」按钮后，程序立即无响应并闪退，进程退出代码 `0xC0000409 (STATUS_STACK_BUFFER_OVERRUN)`。

## 根因
`AdvancedPage` 继承 `NormalPage`，但**没有自定义 `__init__`**，因此走的是父类 `NormalPage.__init__`。父类初始化里 `self.buildUi()` 是虚方法分派，实际调用的是 `AdvancedPage.buildUi`（四步向导配置页），它构建的控件集合与 `NormalPage.buildUi` **不同**：

- 高级模式配置页**没有** `from_edit`（发件人）、`attach_folders`、`_preview_all_generated`、`_preview_rows_total`。
- 任务机制方法 `_serializeTaskConfig` / `_restoreTaskConfig` 却直接硬编码引用了这些不存在的属性。

点击存草稿触发 `onSaveDraft` → `_serializeTaskConfig()`，在访问 `self.from_edit.text()` 处抛出 `AttributeError`。该异常在 PyQt 的 C++ 信号→槽调用链中被抛出，触发了本机 fast-fail 崩溃（退出码 0xC0000409），而不是普通 Python 异常。

## 修复
在 `MainGUI.py` 中把 `_serializeTaskConfig` 与 `_restoreTaskConfig` 改为防御式访问：
- 每个控件字段先用 `hasattr(self, ...)` 判断是否存在，缺失则跳过 / 给默认值，不再硬编码引用。
- 附件模式、预览标志、抄送/密送行展开等同样用 `getattr(..., 默认)` 保护。
- 保证高级模式缺 `from_edit` 等字段时，存草稿与草稿恢复均可正常序列化/反序列化，而不会崩溃。

## 验证
- 直接调用 `onSaveDraft()`：JSON 序列化成功，任务写入「草稿箱」，`_current_task_id` 正确，全程无崩溃。
- `json.dumps` 成功；`_restoreTaskConfig` 后 `title_edit/body_editor/昵称$$`均正确回填，`step_stack` 回到第1步。
- `python -m py_compile` 通过。
