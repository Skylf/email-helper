# Bug: 查询功能仅占位，未实装按条件搜索

**日期**: 2026-08-23
**版本**: v0.0.1F
**优先级**: 中

## 现象
顶部搜索框只显示「搜索邮件（占位）」，点击「查询」按钮仅弹出"查询功能开发中"的提示，
无法按 主题 / 收件人 / 发件人 / 时间范围 实际检索邮件。

## 根因
- 数据库 `searchMails` 只提供单一关键词在「主题/收件人/正文」里的模糊匹配，缺少结构化的
  分条件查询方法，更没有时间范围筛选。
- GUI 顶部栏的「查询」按钮与 `onSearchPlaceholder` 占位实现相连，仅弹 QMessageBox，
  未接入任何查询与结果渲染逻辑。

## 修复
1. 数据库层（src/database/database.py）新增 `queryMails(category, title, recipient, sender,
   date_from, date_to)` 结构化查询方法：各条件可留空（不参与 AND 筛选）、收件人匹配
   收件/抄送/密送、发件人匹配昵称/回信邮箱、时间范围按 `date(send_time)` 日期比较；
   暂不支持按正文搜索。
2. GUI 层（src/GUI/MainGUI.py）：
   - 新增 `SearchDialog` 查询对话框：主题 / 收件人 / 发件人 输入框 + 可选「限定发送日期」
     区间（默认关闭，避免默认日期把结果筛空）。
   - `onSearch` 实装：打开对话框、收集条件、调 `queryMails` 查询并按当前分类范围渲染到列表页。
   - 搜索框回车与「查询」按钮均接入 `onSearch`。

## 验证
- 数据库单测：按主题、收件人、发件人、日期区间、无范围 5 种场景均返回正确结果。
- GUI 单测：`SearchDialog` 收集与清空条件正确；日期范围默认不参与（None），勾选后返回区间。
- `py_compile` 通过。
